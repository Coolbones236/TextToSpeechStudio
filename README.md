# Text To Speech Studio 🎙️

A sleek, modern desktop application designed for generating, previewing, and managing custom text-to-speech audio files.

---

## ✨ Features

* **Modern Workspace UI:** Dark mode interface designed for ease of use and focus.
* **Custom Audio Parameters:** Fine-tune speech playback speed, volume, and system voices.
* **Multiple Output Formats:** Export audio generations directly to `.mp3` or `.wav`.
* **Integrated Generation History:** View, replay, pause, or manage past generated audio files within the dedicated History tab.
* **Customizable Themes:** Switch between color palettes (including Cyberpunk) in Application Settings.

## 📥 Download & Installation

1. Go to the **[Releases](https://github.com/Coolbones236/TextToSpeechStudio/releases)** section on the right side of this page.
2. Download the latest `TextToSpeechStudio.exe` file.
3. Double-click `TextToSpeechStudio.exe` to launch—no installation required!

---

## 🚀 How to Use

1. **Input Text:** Type or paste text into the main workspace, or click **Import File** to load a document.
2. **Configure Voice:** Select your preferred system voice, speed, and volume level.
3. **Generate:** Click **Generate** to preview the audio.
4. **Export:** Select your desired format (`.mp3` or `.wav`) and click **Download** to save the file.

---

## ⚙️ Requirements

* **OS:** Windows 10 / 11 (64-bit)
* No additional setup or Python environment required.
